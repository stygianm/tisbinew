# 05_backend_appstorespybackend

Тестовое задание Appstorespy — REST API для каталога приложений (CRUD).

## Постановка задачи

Junior Backend: Django/Flask, PostgreSQL. Реализован CRUD для приложений.
Источник: Hexlet ru-test-assignments backend/Appstorespy.

## Локальный запуск

1. `createdb appstorespy`
2. `pip install -r requirements.txt`
3. `uvicorn app.main:app --reload`

## Docker

```bash
docker-compose up --build
```

API: http://localhost:8003
