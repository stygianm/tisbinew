# Тестовое задание ООО МСтрой Backend

**Источник:** [Hexlet ru-test-assignments / ООО МСтрой](https://github.com/Hexlet/ru-test-assignments/tree/main/backend/%D0%9E%D0%9E%D0%9E%20%D0%9C%D0%A1%D1%82%D1%80%D0%BE%D0%B9)

Класс TreeStore для работы с древовидной структурой данных.

## Методы

- **getAll()** — возвращает весь массив
- **getItem(id)** — возвращает объект по id
- **getChildren(id)** — возвращает дочерние элементы
- **getAllParents(id)** — возвращает цепочку родителей до корня

## Требования

Максимальное быстродействие, прямой доступ без поиска в массиве.
