# 10_analytics_realwebcampanalytics

Тестовое задание Realweb Camp Analytics — анализ датасета Python.

## Постановка задачи

CSV данные интернет-компании: каналы, выручка, промокоды, CR.
Источник: Hexlet ru-test-assignments analytics/Realweb Camp Analytics.

## Локальный запуск

1. `pip install -r requirements.txt`
2. `python sample_data.py`  # создать тестовые данные
3. `python analyze.py`

## Данные

Оригинальный датасет: Realweb summer_camp_data.csv (см. Hexlet repo).
Или использовать sample_data.py для тестового набора.
